# Liber — liber.net

браузер на chromium с встроенным обходом dpi-блокировок. без кнопок, без меню,
без тумблеров: обход просто работает с запуском браузера, как и должно быть.

```
chrome-совместимое ядро   сайты открываются как в chrome, 1-в-1
обход вшит                desync-движок работает в фоне, включается сам
без прав админа           установка в профиль пользователя, без uac
премиум минималистика     тёмный графит, тонкие линии, ничего лишнего
```

## как работает обход

при старте браузер тихо поднимает встроенный desync-движок
([byedpi](https://github.com/hufrea/byedpi), mit) как локальный socks-прокси
и направляет весь трафик вкладок через него. движок живёт ровно столько, сколько
живёт браузер: пользователь ничего не замечает. если движок по какой-то причине
не поднялся — браузер честно остаётся рабочим на прямом трафике.

## что уже есть

- вкладки; сессия переживает перезапуск вместе с геометрией окна
- закреплённые вкладки: компактные иконки в начале полосы, состояние переживает перезапуск
- группы вкладок: цветные ярлыки, сворачивание и разворачивание, переименование и цвет из меню группы
- вертикальные вкладки: панель слева, включается в меню ⋮
- несколько окон (ctrl+n) и инкогнито (ctrl+shift+n): приватные вкладки не пишут историю и не сохраняются
- поиск по вкладкам (ctrl+shift+a)
- омнибокс: подсказки из истории и закладок, автодополнение по мере ввода, замок https/«не защищено»
- вкладки: контекстное меню (дублировать, закрыть другие/вправо), «без звука», индикатор звука, прокрутка при переполнении
- история (ctrl+h) с поиском по записям, закладки (ctrl+d, звёздочка, полка, ctrl+shift+b)
- папки закладок: боковая панель на странице закладок, перенос по папкам, папки на полке
- импорт закладок и истории из chrome, edge, brave, яндекс, opera и firefox (настройки → импорт)
- экспорт и импорт закладок в html-файл (страница закладок)
- страница «загрузки» (ctrl+j): открыть файл, показать в папке, пауза, отмена
- pdf открывается внутри браузера
- сохранение страницы (ctrl+s), печать (ctrl+p), просмотр кода (ctrl+u)
- полный экран (f11); видео разворачивается без панелей
- восстановление вкладки после падения страницы
- поиск по странице (ctrl+f); зум (ctrl+плюс/минус/ноль, колесо с ctrl) с запоминанием масштаба для сайта
- контекстное меню: ссылки, копирование, картинки, «искать выделенное», навигация, проверка орфографии
- менеджер паролей: хранилище шифруется средствами windows, автозаполнение форм входа, предложение сохранить пароль после входа
- режим чтения (f9): своя страница liber://reader, текст статьи вырезается из страницы и чистится
- перевод страницы через веб-переводчик (пкм → перевести страницу)
- вернуть закрытую вкладку (ctrl+shift+t), вперёд-назад (alt+стрелки, f5, alt+home)
- вкладки-попапы, микрофон, камера, шаринг экрана и уведомления
- блокировщик рекламы и трекеров: easylist, easyprivacy и ruadlist, скрытие рекламных блоков на страницах, исключения для отдельных сайтов, статистика и обновление списков в настройках
- разрешения по сайтам: камера, микрофон, геолокация, уведомления, буфер обмена и захват экрана спрашиваются у пользователя и запоминаются; для конкретного сайта можно выключить javascript, куки, картинки и попапы
- свои поисковики: адрес с %s, ярлык в омнибоксе («d котики» ищет в duckduckgo)
- настройки: поисковик, домашняя страница, папка загрузок, блокировка рекламы, разрешения сайтов, свои поисковики, очистка данных, «сделать браузером по умолчанию»
- меню ⋮ и полный набор сочетаний (ctrl+1..9, ctrl+tab, ctrl+l/f/h/j/u/s/p/d)

## запуск из исходников

```
npm install
npm start
```

## сборка

```
npm run pack     папка без установщика: dist\win-unpacked
npm run dist     установщик и portable-сборка в dist\
```

установщик ставится в профиль пользователя (без uac), кладёт ярлыки на рабочий
стол и в пуск, регистрирует liber.net в системе как браузер — после этого он
появляется в списке «приложения по умолчанию» винды. desync-движок лежит рядом
с приложением в resources\engine и запускается из него же.
