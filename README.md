**liber.net** — браузер на базе Chromium со встроенным обходом DPI-блокировок.
Обход работает из коробки: без кнопок, переключателей и настройки в интерфейсе.
Движок поднимается вместе с браузером и так же незаметно завершается вместе с ним.

```
Chrome-совместимое ядро   сайты открываются так же, как в Chrome
Обход встроен            desync-движок работает в фоне и запускается сам
Без прав администратора  установка в профиль пользователя, без UAC
Минималистичный дизайн   тёмный графит, тонкие линии, ничего лишнего
```

## Возможности

### Обход блокировок

- встроенный desync-движок ([byedpi](https://github.com/hufrea/byedpi), MIT): запускается и останавливается вместе с браузером;
- автоматический подбор рабочей стратегии из девяти предустановленных;
- проверка стратегии настоящим TLS-handshake, а не формальной проверкой открытого порта;
- маршрутизация по домену: сайты из списка исключений идут напрямую, остальные — через движок;
- определение прямого доступа: если сеть не блокируется (VPN или свободное подключение), браузер работает напрямую и не пропускает трафик через движок;
- автоматический перезапуск движка при сбое и повторный подбор стратегии из настроек.

### Вкладки и окна

- вкладки с сохранением сессии и геометрии окна между запусками;
- закреплённые вкладки и группы вкладок (цвет, сворачивание, переименование);
- вертикальные вкладки — панель слева;
- несколько окон и режим инкогнито (приватные вкладки не пишут историю и не сохраняются);
- поиск по открытым вкладкам и восстановление закрытой вкладки;
- контекстное меню вкладок, индикатор и отключение звука, прокрутка при переполнении;
- вкладки-попапы, микрофон, камера, захват экрана и уведомления.

### Приватность и данные

- блокировщик рекламы и трекеров на базе EasyList, EasyPrivacy и RU AdList;
- скрытие рекламных элементов на страницах, исключения для отдельных сайтов, статистика;
- автоматическое обновление списков фильтров;
- менеджер паролей: хранилище шифруется средствами Windows (DPAPI), есть автозаполнение форм входа и предложение сохранить пароль после входа;
- разрешения по сайтам: камера, микрофон, геолокация, уведомления, буфер обмена и захват экрана запрашиваются у пользователя и запоминаются;
- для конкретного сайта можно отключить JavaScript, куки, картинки и всплывающие окна;
- импорт закладок и истории из Chrome, Edge, Brave, Яндекс.Браузера, Opera и Firefox.

### Работа со страницей

- режим чтения (F9): текст статьи вырезается из страницы и открывается на внутренней странице `liber://reader`;
- встроенный просмотр PDF;
- сохранение страницы (Ctrl+S), печать (Ctrl+P), просмотр исходного кода (Ctrl+U);
- поиск по странице и зум с запоминанием масштаба для отдельного сайта;
- перевод страницы через веб-переводчик;
- контекстное меню: ссылки, копирование, изображения, поиск по выделенному, проверка орфографии;
- восстановление вкладки после падения страницы.

### Настройки и интерфейс

- омнибокс с подсказками из истории и закладок, автодополнением и индикатором HTTPS;
- история с поиском, закладки с папками и полкой, экспорт и импорт закладок в HTML;
- страница загрузок с управлением файлами;
- собственные поисковики (адрес с `%s` и ярлык в омнибоксе);
- меню и полный набор горячих клавиш;
- тёмная минималистичная тема.

## Как работает обход блокировок

1. **Проверка сети.** При запуске браузер проверяет, доступен ли прямой TLS-доступ. Если сеть не блокируется, трафик идёт напрямую — движок в этом случае не нужен и не используется.
2. **Подбор стратегии.** Если прямой доступ недоступен, браузер по очереди проверяет предустановленные desync-стратегии: для каждой временно поднимается движок, через него выполняется настоящий TLS-handshake, и первая сработавшая стратегия закрепляется как рабочая.
3. **Движок.** `engine/ciadpi.exe` запускается как локальный SOCKS5-прокси на `127.0.0.1:1079` и живёт ровно столько, сколько живёт браузер.
4. **Маршрутизация.** Отдельный SOCKS5-шим (`src/routing.js`, `127.0.0.1:1078`) принимает соединения от сессии Chromium и решает по домену: отправить напрямую или через движок. Соединения к IP-адресам и доменам из списка исключений идут в обход движка.
5. **Отказоустойчивость.** Если движок не поднялся или упал, браузер остаётся полностью рабочим на прямом трафике, а движок автоматически перезапускается (до 30 попыток). Стратегию можно сменить или подобрать заново из настроек.

## Архитектура

| Путь | Назначение |
|---|---|
| `src/main.js` | главный процесс: окна, вкладки, сессии, IPC, внутренние страницы `liber://`, менеджер паролей, импорт данных, QA-стенд |
| `src/bypass.js` | жизненный цикл движка обхода: подбор стратегии, запуск и перезапуск `ciadpi.exe` |
| `src/routing.js` | SOCKS5-шим: маршрутизация по домену — напрямую или через движок |
| `src/adblock.js` | блокировщик рекламы и трекеров: сопоставление правил и скрытие элементов |
| `src/storage.js` | хранилище настроек и данных пользователя |
| `src/preload.js`, `src/content-preload.js` | мосты между процессами и страницами |
| `src/ui/*.html`, `src/ui/app.js` | интерфейс браузера и внутренние страницы |
| `engine/ciadpi.exe` | desync-движок (byedpi, MIT) |
| `build/` | иконка, скрипты NSIS-установщика и регистрации браузера в системе |

## QA-стенд

В проекте есть собственный стенд для проверки интерфейса и регрессии. Он не требует внешних инструментов и включается переменными окружения.

| Переменная | Действие |
|---|---|
| `LIBER_SELFTEST=1` | самотест: окна, вкладки, навигация, режим чтения, блокировщик, импорт; скриншоты складываются в `_dev/` |
| `LIBER_UIQA=<страница>` | рендер внутренней страницы в скрытом окне, снятие метрик вёрстки и серия скриншотов |
| `LIBER_UIQA_PARTS=<n>` | число прокручиваемых частей страницы при съёмке UIQA (по умолчанию 6) |
| `LIBER_SHOTS=1` | серия скриншотов интерфейса и всех внутренних страниц в `_dev/` |
| `LIBER_SHOT_URL=<url>` | дополнительно снять внешнюю страницу |
| `LIBER_DEBUG=1` | подробный лог маршрутизации и событий |
| `LIBER_BYPASS=off` \| `force` | принудительно выключить или включить обход |
| `LIBER_USERDATA=<путь>` | переопределить каталог профиля |

Примеры:

```
set LIBER_SHOTS=1 && npm start
set LIBER_SELFTEST=1 && npm start
set LIBER_UIQA=settings && npm start
```

## Технологии

- **Electron** — оболочка приложения;
- **Chromium** — движок рендеринга;
- **Node.js** — главный процесс и сетевые компоненты;
- **byedpi** — desync-движок обхода;
- **electron-builder** и **NSIS** — сборка дистрибутива и установщика.

## Требования

- Windows 10/11, x64;
- Node.js 20+ и npm — для запуска из исходников.

## Запуск из исходников

```sh
git clone https://github.com/palychdev/liber.net
cd liber.net
npm install
npm start
```

## Сборка дистрибутива

```sh
npm run pack     # папка без установщика: dist\win-unpacked
npm run dist     # установщик и portable-сборка в dist\
```

Установщик ставится в профиль пользователя (без UAC), создаёт ярлыки на рабочем столе и в меню «Пуск» и регистрирует liber.net в системе как браузер — после этого он появляется в списке «Приложения по умолчанию». Движок лежит рядом с приложением в `resources\engine` и запускается оттуда же.
